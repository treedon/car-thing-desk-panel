# Specs and plans

How each feature was planned, kept as it was written. The project was built
with [Claude Code](https://claude.com/claude-code) and the
[Superpowers](https://github.com/obra/superpowers) skills: a feature starts as
a spec in `specs/` (what and why, approved before any code), then becomes a
step-by-step plan in `plans/` that the build follows.

They are a record, not documentation: the README describes what the project
does now. They mention the author's own machines (a Mac, a Windows mini PC
called the NucBox, a smart mirror) and dates as they were at the time. PR
numbers refer to the private repository the project was developed in.
