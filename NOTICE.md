# Notice

`mac-service/`, `panel/`, `simulator/` and `protocol/` began as copies of
[rithkott/claude-thing](https://github.com/rithkott/claude-thing)
(commit `920192b`, 2026-08-06): `daemon/`, `device-app/`, `emulator/` and
`protocol/` respectively. claude-thing is licensed under the GNU GPL v3.0, so
this repository is too; see [LICENSE](LICENSE).

Removed from the copies: the Nocturne firmware extraction, phone simulation and
mock nocturned WebSocket server in the emulator, and the Bluetooth screen in the
device app. This project runs the panel directly against the Mac service.

The pixel mascot sprites (`panel/src/sprites/`, generated by
`panel/scripts/gen-sprites.js`) came with that copy.

## Not included here

These are fetched when you build or install, each under its own license:

- The Car Thing image's base,
  [JoeyEamigh/yocto-superbird](https://github.com/JoeyEamigh/yocto-superbird),
  and the Yocto layers it pulls in (`device/kas/panel.yml` pins the commit).
  `device/meta-panel/` only adds to it.
- npm packages, listed in each `package.json` and `package-lock.json`.
- whisper.cpp and its speech model, FFmpeg, LibreHardwareMonitor, and the
  other tools named in the [README's credits](README.md#credits).
